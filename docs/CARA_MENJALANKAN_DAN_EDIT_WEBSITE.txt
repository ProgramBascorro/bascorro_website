TUTORIAL MENJALANKAN DAN MENGEDIT WEBSITE BASCORRO DI LOCALHOST
=================================================================

Dokumen ini menjelaskan cara menyalakan website di komputer lokal,
software yang diperlukan, cara mengedit isi website, dan cara mengatasi
error umum.

Project ini adalah website Next.js dengan Fumadocs. Artinya:
- Halaman website dibuat dengan React/TypeScript di folder src/app.
- Konten dokumentasi dibuat dengan file MDX di folder content/docs.
- Gambar, logo, PDF, dan aset publik disimpan di folder public.
- Dependency dikelola dengan pnpm.


1. SOFTWARE YANG DIPERLUKAN
===========================

Install software berikut sebelum menjalankan website.

1. Node.js
----------
Gunakan Node.js versi LTS terbaru. Rekomendasi aman:
- Node.js 20 LTS, atau
- Node.js 22 LTS

Cek versi Node.js:

  node -v

Kalau command tersebut belum ada, install Node.js dari:

  https://nodejs.org/

Di Linux, lebih rapi memakai nvm:

  https://github.com/nvm-sh/nvm


2. pnpm
-------
Project ini memakai pnpm. Di package.json tertulis package manager:

  pnpm@10.15.1

Cara paling aman mengaktifkan pnpm adalah lewat Corepack:

  corepack enable
  corepack prepare pnpm@10.15.1 --activate

Cek versi pnpm:

  pnpm -v


3. Git
------
Git diperlukan untuk clone project, melihat perubahan, dan commit.

Cek Git:

  git --version


4. Code Editor
--------------
Rekomendasi:
- Visual Studio Code
- Cursor
- Zed
- WebStorm

Extension yang berguna di VS Code:
- ESLint
- Biome
- Tailwind CSS IntelliSense
- MDX
- TypeScript and JavaScript Language Features


5. Browser
----------
Gunakan browser modern:
- Google Chrome
- Microsoft Edge
- Firefox

8. STRUKTUR FOLDER PENTING
==========================

package.json
------------
Berisi script command dan daftar dependency.

Script penting:

  pnpm dev          menjalankan website untuk development
  pnpm build        membuat production build
  pnpm start        menjalankan hasil production build
  pnpm lint         cek format/lint dengan Biome
  pnpm format       format code
  pnpm test:unit    menjalankan unit test
  pnpm types:check  cek MDX, Next typegen, dan TypeScript


src/app
-------
Berisi route utama website.

Contoh:

  src/app/(home)/page.tsx
  src/app/team/page.tsx
  src/app/gallery/page.tsx
  src/app/competitions/page.tsx
  src/app/robocup/page.tsx
  src/app/dataset-lab/page.tsx

Kalau ingin membuat halaman baru, biasanya buat folder baru di src/app.
Contoh membuat halaman contact:

  src/app/contact/page.tsx

Maka URL-nya menjadi:

  http://localhost:3000/contact


src/components
--------------
Berisi komponen React yang dipakai oleh halaman.

Contoh:

  src/components/landing
  src/components/dataset-lab
  src/components/docs
  src/components/learning
  src/components/shared
  src/components/ui

Kalau ada bagian halaman yang berulang atau besar, sebaiknya dibuat
sebagai component di folder ini.


content/docs
------------
Berisi konten dokumentasi dalam format MDX.

MDX mirip Markdown, tetapi bisa memakai komponen React.

Contoh file:

  content/docs/index.mdx
  content/docs/getting-started/installation.mdx
  content/docs/software/vision.mdx
  content/docs/learning/ros/ros2-basics.mdx

Kalau ingin mengedit isi halaman docs, edit file MDX di folder ini.


public
------
Berisi file statis yang bisa diakses langsung oleh browser.

Contoh:

  public/Logo_Bascorro.png
  public/robot1.jpeg
  public/robot2.jpeg
  public/team/2025
  public/team/2026

Contoh penggunaan gambar dari public:

  /Logo_Bascorro.png
  /robot1.jpeg
  /team/2026/nama-file.jpg


src/data
--------
Berisi data JSON yang dipakai website.

Contoh:

  src/data/team-2025.json
  src/data/team-2026.json

Kalau ingin mengedit data anggota tim, cek file JSON di folder ini.


src/app/global.css
------------------
Berisi style global website.

Edit file ini kalau ingin mengubah style global, warna umum, typography,
atau utility CSS yang berlaku luas.

===================================

Contoh ingin menambah halaman:

Isi minimal:

  description: Catatan sistem navigasi robot.
  ---

  # Navigation

  Isi dokumentasi di sini.

Lalu update meta.json di folder yang sama kalau ingin halaman muncul
di sidebar dengan urutan tertentu.

18. TROUBLESHOOTING ERROR UMUM
==============================

Error: command not found: pnpm
------------------------------
Solusi:

  corepack enable
  corepack prepare pnpm@10.15.1 --activate

Lalu cek:

  pnpm -v


Error: command not found: node
------------------------------
Solusi:
- Install Node.js 20 LTS atau 22 LTS.
- Tutup dan buka ulang terminal.
- Cek lagi dengan:

  node -v


Error: port 3000 already in use
-------------------------------
Artinya port 3000 sedang dipakai aplikasi lain.

Solusi 1:
- Ikuti port lain yang ditawarkan Next.js.

Solusi 2:
- Cari proses yang memakai port 3000:

  ss -ltnp | grep 3000

atau:

  lsof -i :3000

Lalu matikan proses yang tidak diperlukan.


Website tidak berubah setelah diedit
------------------------------------
Solusi:
1. Refresh browser.
2. Pastikan file yang diedit memang file yang dipakai halaman tersebut.
3. Cek terminal pnpm dev apakah ada error.
4. Stop server dengan Ctrl + C, lalu jalankan ulang:

  pnpm dev


Error dependency atau module tidak ditemukan
--------------------------------------------
Solusi:

  pnpm install

Kalau masih error, hapus cache build Next.js:

  rm -rf .next
  pnpm dev

Catatan: jangan hapus folder lain seperti src, content, public, atau
file project penting.


Error dari env atau variable kosong
-----------------------------------
Solusi:
1. Pastikan file .env.local ada.
2. Bandingkan dengan .env.example.
3. Isi variable yang diperlukan.
4. Restart pnpm dev setelah mengubah .env.local.

Next.js membaca env saat server dinyalakan. Jadi perubahan .env.local
sering butuh restart server.


Halaman docs error setelah menambah MDX
---------------------------------------
Cek:
1. Frontmatter MDX benar.
2. Heading Markdown benar.
3. Komponen React yang dipakai sudah diimport.
4. meta.json valid JSON.
5. Tidak ada koma berlebih di JSON.

Jalankan:

  pnpm types:check
