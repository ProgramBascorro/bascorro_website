## What is a Robot?

Robot adalah sistem mekanik yang dapat:

1. **Sense** - Merasakan lingkungan melalui sensor
2. **Plan** - Memproses informasi dan membuat keputusan
3. **Act** - Melakukan aksi melalui aktuator

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   SENSE     │────▶│    PLAN     │────▶│     ACT     │
│  (Sensors)  │     │  (Control)  │     │ (Actuators) │
└─────────────┘     └─────────────┘     └─────────────┘
       ▲                                       │
       └───────────── Feedback ────────────────┘
```

## Humanoid Robot Components

### Mechanical System

- **Frame/Body** - Struktur fisik robot
- **Joints** - Titik rotasi yang memungkinkan gerakan
- **Degrees of Freedom (DoF)** - Jumlah axis gerakan independen

### Electronic System

- **Microcontroller/Computer** - Otak robot
- **Motor Drivers** - Pengontrol motor
- **Power System** - Baterai dan distribusi daya

### Software System

- **Operating System** - ROS 2
- **Control Algorithms** - PID, balance control
- **Perception** - Computer vision, sensor fusion

## Key Concepts

### Coordinate Systems

Robot menggunakan sistem koordinat untuk menentukan posisi:

| Frame              | Description                           |
| ------------------ | ------------------------------------- |
| World Frame        | Koordinat global tetap                |
| Base Frame         | Koordinat relatif terhadap base robot |
| End-Effector Frame | Koordinat di ujung manipulator        |

### Transformations

Transformasi digunakan untuk mengkonversi antara coordinate frames:

```
T = [R | t]
    [0 | 1]

R = Rotation matrix (3x3)
t = Translation vector (3x1)
```
