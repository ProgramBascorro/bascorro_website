# Git Fundamentals

Track ini dibuat untuk anggota BASCORRO yang baru mulai bekerja dengan repository tim. Fokusnya: **kebiasaan kerja yang benar** agar kamu bisa kontribusi tanpa merusak branch orang lain.

<Callout type="info">
  Git adalah alat untuk **mencatat perubahan**, bukan hanya sekadar backup. Kalau kamu paham konsep ini, semua perintah Git jadi masuk akal.
</Callout>

---

## Learning Outcomes

Setelah track ini, kamu bisa:

- Membuat commit yang rapi dan mudah direview.
- Kerja di branch sendiri tanpa ganggu branch utama.
- Sinkronisasi dengan remote (`origin` dan `upstream`).
- Undo kesalahan tanpa merusak history tim.
- Menangani konflik sederhana saat merge.

## Quick Glossary

- **Repository**: folder proyek yang sudah di-inisialisasi Git.
- **Commit**: snapshot perubahan yang punya pesan dan ID.
- **Branch**: jalur kerja terpisah dari branch utama.
- **Remote**: copy repository di server (misalnya GitHub).
- **HEAD**: posisi kerja kamu sekarang.
