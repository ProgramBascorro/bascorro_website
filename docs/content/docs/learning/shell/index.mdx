# Shell & Linux Basics

Track ini untuk anggota BASCORRO yang masih baru dengan terminal. Fokusnya: command line yang dipakai setiap hari saat setup, debugging, dan development robot.

<Callout type="info">
  Kalau kamu nyaman pakai terminal, workflow ROS 2 dan Git akan jauh lebih cepat.
</Callout>

---

## Learning Outcomes

Setelah menyelesaikan track ini, kamu bisa:

- Navigasi file system Linux tanpa bingung.
- Kelola file dan folder dengan aman dari terminal.
- Pakai pipe dan redirection untuk analisis output command.
- Cari file atau teks penting dengan cepat (`rg`, `grep`).
- Menulis script Bash sederhana untuk otomatisasi task rutin.

## Safety Rules

- Selalu cek folder aktif dengan `pwd` sebelum menjalankan command perubahan file.
- Hindari command destruktif tanpa verifikasi (`rm -r`, `mv` ke path yang tidak jelas).
- Pakai `-i` saat ragu (`cp -i`, `mv -i`, `rm -i`).
- Gunakan `sudo` hanya ketika memang diperlukan dan kamu paham efeknya.

<Callout type="warning">
  Command di terminal langsung mengubah sistem. Biasakan verifikasi command
  sebelum tekan Enter.
</Callout>
